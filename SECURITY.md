# Security Policy

## Supported Versions
Only the latest release on the `main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within this repository or studio template:
1. Please **do not** open a public issue.
2. Email your findings directly to `talaripradeep14@gmail.com`.
3. Provide a minimal reproduction example and description of the impact.
4. You will receive an acknowledgment within 24–48 hours with remediation tracking.
